## 🌟 Our Projects

The Alchemical-3D ecosystem consists of several active projects designed to tackle distinct challenges in modern 3D printing:

### 🧪 [Alembic (Toolhead)](https://github.com/Alchemical-3D/Alembic)
A highly specialized, lightweight toolhead replacing bulky fans with a rigid, compressed air cooling architecture. Designed to integrate seamlessly with Pneuma for high-performance part cooling and unobstructed nozzle visibility.  Alembic has proven to manage bridging and overhangs in a superior manner while also reducing toolhead weight and footprint.  This system penetrates the thermal boundary layer easily for optimal cooling.
* **Key Features:** High Speed Air Part Cooling, Lightweight Frame, Dedicated Umbilical Routing.

### 💨 [Pneuma (Remote Air Cooling)](https://github.com/Alchemical-3D/Pneuma_Remote_Air)
A remote pneumatic driven toolhead cooling system. By replacing cooling fans in the print head, Pneuma reduces toolhead mass, enabling higher accelerations and speeds without sacrificing part cooling performance.  By using low noise pumps designed for other related purposes, the noise levels of Pneuma are comparable to traditional fan systems. This system penetrates the thermal boundary layer easily for optimal cooling.
* **Key Features:** Remote Blower Integration, Optimized Airflow Routing, High Overhang and Bridge Performance, High Speed Printing.

### 💧 [Retort-A (Dehumidifier)](https://github.com/Alchemical-3D/Retort)
An active, solid-state filament dehumidification system. Retort provides consistent, controlled environments for hygroscopic filaments, driven by a custom control board.  The primary function of this project is filament storage, but its use cases are infinite where granualar moisture control is desired.
* **Key Features:** Closed Loop Environmental Control.

### 💧 [Retort-B (Filament Dryer)](https://github.com/Alchemical-3D/Retort)
An active, solid-state/dessicant based filament system. Retort provides consistent, controlled environments for hygroscopic filaments, driven by a custom control board.  The primary function of this project is drying engineering grade filaments, but its use cases extend to almost all common filaments.
* **Key Features:** Hight Temp Filament Dryer, Closed Loop Environmental Control.

### 🥣 [Pestle (Rotational Bowden)](https://github.com/Alchemical-3D/Pestle)
A flexible, ultra-lightweight extruder designed to ride the X-gantry (or elsewhere) with full rotational movement. Pestle allows for the shortest possible Bowden tube routing by removing bend radii from the extrusion path as it angles toward toolhead locations, decreasing Pressure Advance values while keeping the toolhead exceptionally light.  This system was designed particularly for use with Cartesian printers.
* **Key Features:** Free Rotating Assembly, BMG Internals, Nema 14 Support, High Quality Printing.
